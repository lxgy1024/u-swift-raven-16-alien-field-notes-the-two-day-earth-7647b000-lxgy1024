## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program writes one line of plain text (1–200 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
